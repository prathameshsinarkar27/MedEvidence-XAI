# Sample data (synthetic)

Every file here is **synthetic**: generated by `scripts/generate_sample_pdfs.py` with invented names and values.
They contain no real patient information. **Never add real patient data to this repository.**

| File | What it is | Exercises |
|------|-----------|-----------|
| `synthetic_lab_report_text.pdf` | 2 pages with a normal text layer (lab report + discharge summary) | PDF text extraction (no OCR needed) |
| `synthetic_lab_report_scanned.pdf` | 1 page that is only an image (no text layer) | Scanned-page detection + Tesseract OCR |
| `synthetic_mixed_report.pdf` | Page 1 text, page 2 is image-only | Per-page choice between text layer and OCR |
| `synthetic_multimodal_report.pdf` | Page 1: a ruled table, a borderless table, a bar-chart picture and a picture of printed text; page 2: prose only | Table detection, cell text, image extraction, source regions, optional image OCR |
| `synthetic_clinical_note.pdf` | One page: a short clinic note (negated and uncertain findings, family history, allergy, medications, vitals, dates) plus a ruled lab table | Clinical information extraction, assertion handling, date normalisation, table-row evidence |
| `synthetic_rotated_table.pdf` | One table on a page stored with a 90-degree rotation | Source-region mapping on rotated pages |

Regenerate with `python scripts/generate_sample_pdfs.py` (needs the backend virtualenv). The values in the documents
are invented; they are not clinical examples and say nothing about real patients or ranges.
